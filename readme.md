<a href="https://henri-simoncini.github.io/outlast-fanpage"><h1>👁️ Outlast Fanpage</h1></a>
<table>
    <tr>
        <td width="50%" valign="top">            
            <p>Uma fanpage dedicada à franquia Outlast, trazendo uma experiência imersiva inspirada na estética de horror 
            psicológico da série.</p>
            <hr>
            <h3>🧠 Sobre o Projeto</h3>
            <p>Este projeto é um site front-end desenvolvido com foco em:</p>
            <ul>
                <li>Design imersivo (estilo câmera noturna / found footage)</li>
                <li>Experiência interativa</li>
                <li>Layout moderno e responsivo</li>
            </ul>
            <p>A proposta é simular um sistema da <b>Murkoff Corporation</b>, onde o usuário navega por conteúdos como se
            estivesse acessando arquivos confidenciais.</p>
            <hr>
            <h3>🎨 Features</h3>
            <ul>
                <li>🎥 Hero com estética de câmera (REC + HUD)</li>
                <li>📰 Seção de notícias</li>
                <li>📖 HQs da franquia</li>
                <li>🎮 Jogos com trailers</li>
                <li>🖼️ Galeria de imagens</li>
                <li>📜 Seção “Sobre”</li>
            </ul>
            <hr>
            <h3>⚡ Efeitos visuais:</h3>
            <ul>
                <li>Glitch</li>
                <li>Scanlines</li>
                <li>Vinheta (radial gradient)</li>
                <li>🔗 Navegação com scroll spy (link ativo conforme rolagem)</li>
            </ul>
        </td>
